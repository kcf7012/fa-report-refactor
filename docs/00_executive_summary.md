---

## 🎯 一句話總結

**v2.3.0 技能包能用,但很笨** — 內容擠在一起、版面不好看、需要預先準備 JSON、無法獨立運作。v3.0 要把它變成「**專業、聰明、可獨立運作**」的工具。

---

## ⚡ 三件最重要的事

### 1. 🛡️ 母片絕對不能被破壞
- ELAN 公司模板、Logo、機密標示都是品牌資產
- v3.0 會加入**自動測試**,確保母片 XML 完全不變
- 任何改善都必須沿用既有 layout,不可新增/刪除 layout

### 2. 🎨 一張投影片只講一件事
- 目前 7 個 bullet 塞一張投影片 → 拆成 3-4 張,各 2-3 個重點
- 加入**視覺元素**(checklist、流程圖、進度條、對照表)
- **Summary 強化不再擠壓**,改為新增獨立的 Executive Summary + Key Improvements 兩張

### 3. 🤖 讓技能包可獨立運作(不用預先準備 JSON)
- 加入 **LLM 整合**(支援 OpenAI API、相容 API、Anthropic、本地 Ollama)
- 使用者只要給 `.pptx`,技能包自己呼叫 LLM 評估 → 自動改善
- 沒有 Coding Agent 或上游 fa_report_analyzer 也能用
